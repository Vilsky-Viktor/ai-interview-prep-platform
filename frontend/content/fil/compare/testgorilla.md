# prepza at TestGorilla: kung saan bagay ang bawat isa, at paggamit sa dalawa

Natural lang na ikumpara ang prepza at TestGorilla, pero hindi talaga sila magkakumpitensya. Nag-aalok ang TestGorilla ng malaking library ng mga handang test, kasama ang cognitive, personality, language at programming tests. Iisa lang ang ginagawa ng prepza: gumagawa ito ng timed multiple-choice na knowledge interview mula sa iyong job description. Maraming hiring process ang puwedeng gumamit ng dalawa, halimbawa ang prepza bilang mabilis at role-specific na knowledge screen, at ang TestGorilla para sa cognitive o personality tests ng mga nasa shortlist.

Ipinapaliwanag ng pahinang ito kung paano sila nagkakaiba, kung saan mas bagay ang bawat isa, at kung paano sila pagsamahin. Ang mga detalye tungkol sa TestGorilla ay mula sa sarili nitong mga pahina noong Oktubre 2026 at puwedeng magbago; tingnan ang mga link bago ka magdesisyon.

## Ang maikling bersyon

- **Bagay ang TestGorilla** kapag kailangan mo ng cognitive ability, personality, language o hands-on coding tests, video questions, ATS integrations o webcam snapshots.
- **Bagay ang prepza** kapag gusto mo ng knowledge test na isinulat mula mismo sa iyong job description, kasama ang code-reading questions para sa mga technical role, at mas gusto mong magbayad bawat kandidato kaysa sa isang plan.
- **Bagay ang dalawa** kapag gusto mo ng role-specific na knowledge screen para sa bawat aplikante at mas malawak na mga test para sa mga papasa rito.

## Paano ginagawa ang mga test

**Ang TestGorilla** ay nagsisimula sa library nito. Pumipili ka ng mga test na bagay sa role (halimbawa, isang role-specific skills test, isang cognitive test at isang personality test) at pinagsasama mo sila sa isang assessment. Nakaayos ang library nito sa mga kategorya gaya ng role-specific skills, programming skills, software skills, language, cognitive ability, situational judgment, personality at culture, at typing ([test library](https://www.testgorilla.com/test-library/)).

**Ang prepza** ay nagsisimula sa iyong job description. Kinukuha nito ang dapat malaman ng kandidato at nagmumungkahi ng mga topic na may mga subtopic. Puwede mong panatilihin, i-uncheck, palitan ang pangalan o i-edit ang mga ito, o ilarawan ang gusto mong pagbabago sa simpleng text. Saka pa lang isinusulat ang mga tanong: isang bank ng multiple-choice questions bawat topic, bawat isa may isang tamang sagot at tatlong kapani-paniwalang maling sagot. Nakikita mo ang bawat tanong at puwede mong i-generate ulit ang alinman dito. Para sa mga technical topic, maraming tanong ang nagpapakita ng maikling code example, query o command at nagtatanong kung ano ang output nito, ano ang ginagawa nito, bakit ito pumapalya o aling pagbabago ang aayos dito.

Ang praktikal na pagkakaiba: nakapirmi ang isang library test at ilang beses nang nagamit, pero hindi ito isinulat para sa iyong role. Ang isang prepza interview ay isinulat para sa iyong role, kasama ang mga partikular na bahagi nito, pero bago ito tuwing gagawa ka. Puwedeng magkamali ang mga tanong na isinulat ng AI, kaya chine-check ng prepza ang mga answer key at pinapabuti ang mga tanong habang sumasagot ang mga kandidato, at puwede mong i-flag ang alinmang tanong.

## Paano gumagana ang presyo

**Ang TestGorilla** ay may libreng plan na may buwanang allowance at mga paid plan na sinisingil taun-taon, na may mas maraming feature sa mas matataas na plan. Tingnan ang [pricing page](https://www.testgorilla.com/pricing/) nito para sa kasalukuyang mga plan at presyo.

**Ang prepza** ay naniningil bawat kandidato:

- Libre ang paggawa ng interview.
- Nagbabayad ka para sa bawat kandidatong sumagot ng kahit isang tanong. Walang bayad ang mga inimbitahang hindi nagsimula; ibinabalik ang kanilang credits.
- Bumababa ang presyo bawat kandidato sa mas malalaking top-up, libre ang unang 3 kandidato mo, hindi nag-e-expire ang credits, at walang subscription. Tingnan ang [presyo](/pricing).

Kung aling modelo ang mas mura ay depende sa dami ng kandidatong tine-test mo sa isang taon at sa mga uri ng test na kailangan mo. Bagay ang isang plan sa tuloy-tuloy at maramihang hiring; bagay ang per-candidate pricing sa paminsan-minsang hiring. Ipinapakita ng [Paano ikumpara ang gastos ng mga test](/compare/cheapest-pre-employment-test) kung paano ito kuwentahin para sa sarili mong volume.

## Karanasan ng kandidato

**prepza:** nakikita ng mga kandidato kung ano ang aasahan bago sila magsimula: na AI ang sumulat ng mga tanong, na mga tao sa iyong kumpanya ang nagre-review ng resulta at nagdedesisyon, at na puwede silang humingi ng dagdag na oras o ng review ng kanilang resulta. May sariling countdown ang bawat tanong. Hindi nakikita ng mga kandidato ang kanilang score o kung aling sagot ang tama. Walang camera na ginagamit.

**TestGorilla:** sa mas mataas nitong plan, kasama sa proctoring ang webcam snapshots, naka-disable na copy/paste at full-screen mode ([pricing page](https://www.testgorilla.com/pricing/)). Mas marami kang nababantayan dito. Ang paggamit ng camera ay pagtitimbang sa pagitan ng pagbabantay at privacy ng mga kandidato, at ang mga larawan mula sa camera ay dagdag na personal data na kailangang protektahan.

## Kung saan mas bagay ang TestGorilla

Magsimula sa kung ano ang kailangan mong i-test. Mas bagay ang TestGorilla kapag:

- **Gusto mo ng psychometrics.** Hindi nag-aalok ang prepza ng cognitive ability, personality at culture tests.
- **Kailangan mo ng hands-on coding o job simulations.** May code-reading questions ang prepza, pero hindi sumusulat o nagpapatakbo ng code ang mga kandidato.
- **Gusto mo ng video answers o AI-led interviews.** Wala ang alinman sa dalawa sa prepza.
- **Kailangan mo ng ATS integrations.** Hindi nag-i-integrate ang prepza sa mga ATS.
- **Malaki at tuloy-tuloy ang dami ng hiring mo** kaya mas mura ang flat plan.
- **Mas gusto mo ang mga handang test na ilang beses nang nagamit** kaysa sa mga test na isinusulat para sa bawat role.

## Kung saan mas bagay ang prepza

- **Partikular ang iyong role.** Sinasaklaw ng test na isinulat mula sa iyong job description ang talagang ginagamit ng iyong team.
- **Paminsan-minsan ka lang nagha-hire.** Iniiwasan ng pagbabayad bawat kandidato ang taunang commitment para sa iilang hire.
- **Gusto mong i-review kung ano ang tine-test** bago maisulat ang kahit isang tanong.
- **Gusto mong may sariling random na set ng tanong ang bawat kandidato,** para mas mahirap ipasa sa iba ang mga sagot.
- **Ayaw mo ng camera monitoring.** Walang video, voice o face analysis ang prepza.
- **Nagha-hire ka sa maraming wika.** Gumagana ang interviews, interface at emails sa 23 wika.

## Paggamit sa dalawa

Puwedeng magsama ang dalawa sa iisang hiring process:

1. **Lahat ng nag-a-apply** ay kumukuha ng maikling prepza knowledge interview na isinulat mula sa job description.
2. **Ang mga pumasa** ay kumukuha ng cognitive, personality o language tests ng TestGorilla, o ng isang coding challenge.
3. **Mga tao ang nagdedesisyon,** gamit ang dalawang resulta kasama ang CV at isang structured interview.

Walang kontrata ang prepza at hindi nag-e-expire ang credits nito, kaya ang pagdagdag nito sa prosesong may ibang tool na ay hindi nagdadagdag ng fixed na gastos.
